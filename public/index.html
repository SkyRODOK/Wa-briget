Setup Firebase
Agar chat realtime antar device

1. Buat Project Firebase

  1. Buka https://console.firebase.google.com
  2. Klik Add project → isi nama project → Create
  3. Nonaktifkan Google Analytics (opsional) → Continue

2. Aktifkan Realtime Database

  1. Di sidebar kiri → Build → Realtime Database
  2. Klik Create Database
  3. Pilih lokasi (mis. Singapore / asia-southeast1)
  4. Mode: pilih Start in test mode dulu (untuk development)
  5. Klik Enable

3. Atur Rules (penting!)

  1. Tab Rules di Realtime Database
  2. Ganti isinya menjadi:
{ "rules": { ".read": true, ".write": true } }
  1. Klik Publish
⚠️ Rules di atas terbuka (siapa saja bisa baca/tulis). Untuk production, batasi dengan auth.

4. Ambil Config Web App

  1. Klik ikon ⚙️ Project settings
  2. Scroll ke Your apps → klik ikon </> (Web)
  3. Isi App nickname (mis. NeoChat) → Register app
  4. Copy object firebaseConfig yang muncul

5. Tempel ke file ini

  1. Buka file chat.html di editor
  2. Cari bagian const firebaseConfig = { ... }
  3. Ganti semua nilai GANTI_DENGAN_... dengan config dari Firebase
  4. Pastikan databaseURL ada (biasanya https://PROJECT-ID-default-rtdb.REGION.firebasedatabase.app)
  5. Simpan file, refresh browser
✅ Setelah config benar, badge di header berubah jadi FB READY dan status "● Terhubung". Pesan akan sinkron realtime antar browser/device.
💡 Tanpa Firebase, chat tetap bisa dipakai di Mode Lokal (hanya di browser ini, data disimpan di localStorage).

Link Audio Langsung
💡 Link TikTok (tiktok.com/...) tidak bisa diputar langsung sebagai nada dering karena TikTok memblokir akses audio dari luar aplikasinya (CORS). Cara yang berhasil: buka video di TikTok → Save video/Save sound, lalu ekstrak audionya jadi file mp3 (mis. lewat app konverter), lalu upload file itu pakai tombol "Upload Audio Sendiri" di atas.

Sambungkan WhatsApp
Menunggu server backend...
1. Pastikan server backend (npm start) sudah jalan.
2. Di HP: WhatsApp → Pengaturan → Perangkat Tertaut → Tautkan Perangkat.
3. Scan QR di atas.
Masukkan nomor WhatsApp kamu sendiri (yang mau di-link). Setelah kode muncul, di HP: Perangkat Tertaut → Tautkan perangkat → Tautkan dengan nomor telepon.
KODE PAIRING
Ketik di WhatsApp sekarang (boleh dengan atau tanpa tanda -)
Format: 62812... (kode negara + nomor). Jangan pakai + atau spasi. Nomor harus sama dengan akun WhatsApp di HP ini. Kode cepat kadaluarsa — kalau ditolak, klik Minta Kode Baru.
